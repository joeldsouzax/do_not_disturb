# Do Not Disturb

Physical D&D remains at the table: painted miniatures, dice, players and a human
Dungeon Master. A shared TV presents cinematic scenes that follow their spoken
story. Players do not navigate a separate generated world or talk to an avatar.

The current prototype starts with camera and microphone access. Players introduce
miniatures by name and class. A pause closes each spoken turn; Gemini recognizes
the figures, attributes intent versus DM narration and asks when uncertain.
Player intent waits for the human DM’s ruling. The screen follows that ruling.

H3 Reference Turbo Realtime directly turns ordered cast references, optional
location images and the
adjudicated visual beat into a short video with synchronized ambient sound.
Continuation carries the previous generated shot’s motion, camera and audio.
At pauses it holds the last frame; it does not invent encounters to stay busy.
Nano Banana can provide optional refined location anchors from the studio;
it does not block the first voice-driven video. The TV layout is the default,
with small game overlays. The example WAV can pause while video prepares.

The main screen has one start action and a spoken sample adventure. The sample
contains actual synthesized DM/player speech and silence and goes through the
same listening pipeline as the microphone. Manual controls and alternate world
models remain on the optional studio route for development comparisons.

See the [template README](../templates/vidu-s2-avatar/README.md) for setup, model
contracts and limitations, and [D&D context notes](dnd-context.md) for sources
and attribution. This local prototype does not implement numerical D&D rules,
biometric speaker identity, physical position tracking or multi-user video
broadcasting. Those should be added only when they support the table experience.

The waiting screen plays a one-time generated promotional trailer. Real games
start without a predefined cast, location or quest: the current camera captures
the miniatures and the human Dungeon Master establishes the world aloud. Demo
recordings have separate state and cannot overwrite the DM’s campaign.
